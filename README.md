## 📊 Using the dashboard

The main dashboard shows your financial state at a glance. You will see a box for your total current balance. Below that, you will find a list of recent items.

### Adding an expense
Click the green "Add Record" button at the top of the screen. A new window will appear. Enter the amount, the category, and the date. Once you press "Save," the main dashboard will update immediately.

### Generating reports
Click the "Reports" tab on the left menu. You can filter your data by month or year. The application allows you to see:

* Total spending by category.
* Comparison between your income and expenses.
* Spending trends over time using simple line graphs.

## ⚙️ Settings and customization

You can change how the software looks. Go to "Settings" to switch between a light mode and a dark mode. This menu also allows you to update your password or export your data into a spreadsheet file if you wish to print your records.

## 🆘 Troubleshooting common issues

If you encounter a problem, check these items first:

* Application does not open: Ensure you installed the .NET Desktop Runtime from the Microsoft official website.
* Data does not save: Check that you have enough space on your hard drive or try running the application as an administrator.
* Slow performance: Close unused browser tabs while you work with the financial app.
* Forgotten password: The app features a recovery file generated during your initial setup. Keep this file in a safe location.

## 🔒 Data privacy

This software does not send your financial data to any external server. Everything stays on your local machine. You own your data. If you delete the application, your data remains in the installation folder unless you choose to remove the database file manually. We value your privacy and keep the system simple and secure.
